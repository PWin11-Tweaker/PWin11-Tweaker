# Таблица ошибок PWin11 Tweaker

Ниже приведены ошибки, которые могут возникнуть при использовании приложения PWin11 Tweaker, их коды, описания, возможные причины и рекомендации по устранению.

При возникнавении таких ошибок, свяжитесь с разработчиком через Issues или через тг канал(который есть на моей страничке в гитхабе или в самой программе)

| Код ошибки | Описание ошибки                              | Возможная причина                                                                 | Рекомендация для пользователя                                                                 |
|------------|----------------------------------------------|-----------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------|
| E001       | Программа запущена не от имени администратора | Приложение требует прав администратора для выполнения некоторых функций.          | Запустите приложение от имени администратора: щёлкните правой кнопкой мыши по .exe файлу и выберите "Запуск от имени администратора". |
| E002       | Неверный формат URL                          | URL, указанный в приложении, некорректен (например, для открытия страницы GitHub). | Убедитесь, что URL в настройках приложения корректен (например, https://github.com/PWin11-Tweaker/PWin11-Tweaker). Если проблема сохраняется, обратитесь к разработчику. |
| E003       | Не удалось открыть страницу в браузере       | В системе не настроен браузер по умолчанию или отсутствует подключение к интернету. | Убедитесь, что у вас установлен браузер по умолчанию (например, Edge, Chrome) и есть доступ к интернету. Попробуйте открыть ссылку вручную. |
| E004       | Ошибка при установке кастомной иконки        | Файл иконки `logo.ico` отсутствует в папке `Assets`.                              | Убедитесь, что файл `logo.ico` находится в папке `Assets` приложения. Если его нет, обратитесь к разработчику. |
| E005       | MicaBackdrop не поддерживается               | Текущая версия Windows не поддерживает эффект Mica (например, Windows 10).        | Обновите Windows до версии 11 или выше. Если обновление невозможно, обратитесь к разработчику для отключения этой функции. |
| E006       | Ошибка навигации: страница не найдена        | Одна из страниц приложения (например, HomePage, SettingsPage) не может быть загружена. | Перезапустите приложение. Если ошибка повторяется, обратитесь к разработчику.                 |
| E007       | Ошибка навигации: ContentFrame не инициализирован | Внутренняя ошибка приложения, связанная с навигацией между страницами.            | Перезапустите приложение. Если ошибка повторяется, обратитесь к разработчику.                 |
| E008       | Ошибка навигации: неизвестный тег страницы   | Выбранный пункт меню имеет некорректный тег, который не соответствует ни одной странице. | Перезапустите приложение и попробуйте снова. Если ошибка сохраняется, обратитесь к разработчику. |
| E009       | Ошибка при сохранении настроек темы          | Не удалось сохранить настройки темы в локальных настройках.                       | Убедитесь, что у приложения есть права на запись в локальные настройки. Перезапустите приложение. |
| E010       | Операция отменена                            | Асинхронная операция (например, открытие страницы) была отменена.                 | Попробуйте снова. Если ошибка повторяется, проверьте стабильность системы и обратитесь к разработчику. |
| E011       | Общая ошибка приложения                      | Неизвестная ошибка, связанная с выполнением приложения.                           | Перезапустите приложение. Если ошибка повторяется, обратитесь к разработчику с описанием проблемы и логами (если доступны). |
