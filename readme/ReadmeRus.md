## Начало работы

0. Нажмите "Star" и "Follow" организацию

1. Загрузка: Клонируйте репозиторий или скачайте последнюю версию со страницы GitHub.

## О проекте

![Tweaker](https://github.com/PWin11-Tweaker/PWin11-Tweaker/blob/main/img/screenPWin11.png?raw=true)

PWin11 Tweaker — это легкое приложение с открытым исходным кодом, которое позволяет настраивать различные аспекты Windows 11 без погружения в сложные системные настройки или использования стороннего ПО. Сосредоточившись на оптимизации производительности, очистке системы, защите конфиденциальности и настройке интерфейса, этот инструмент упрощает процесс адаптации вашей ОС под ваши конкретные нужды. Интуитивная навигация и отзывчивый дизайн делают его доступным для всех, в то время как расширенные опции удовлетворят запросы энтузиастов.

## Ключевые особенности:

   • Оптимизация системы: Повысьте производительность вашей системы, настраивая такие параметры, как программы автозагрузки, фоновые процессы и визуальные эффекты.

   • Защита конфиденциальности: Возьмите под контроль свои данные с помощью опций отключения телеметрии, очистки истории действий и управления службами определения местоположения.

   • Настройка интерфейса: Персонализируйте внешний вид Windows 11 с помощью переключения тем, настройки панели задач и многого другого.

   • Очистка временных файлов: Безопасно удаляйте временные файлы, содержимое корзины, кеши браузеров и остаточные файлы обновлений Windows для освобождения места на диске.

   • Улучшения Проводника: Настройте поведение Проводника файлов, включите скрытые функции и повысьте эффективность навигации.

   • Тонкая настройка производительности: Оптимизируйте игровую производительность, схемы управления питанием и использование памяти несколькими кликами.

   • Удобная навигация: Легко переключайтесь между страницами настроек с помощью современного интерфейса NavigationView с плавными анимациями DrillIn.

   • Контроль прав администратора: Предупреждает, если приложение не запущено с правами администратора, обеспечивая полный доступ к системным твикам.

## Системные требования:

   • Операционная система: Windows 11 (64-битная)

   • Фреймворк: .NET 9.0 или новее

   • Права: Для некоторых функций рекомендуются права администратора.
